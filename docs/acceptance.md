# Manual acceptance

Use demo mode unless you are checking a real model on purpose.

- [ ] Demo banner is visible and sign-in is required.
- [ ] Paste text, see it leave “Saved” or “Processing”, and reach “Ready”.
- [ ] The summary is labeled as a demo preview in demo mode.
- [ ] Open the item, read the original text, and edit the note.
- [ ] Accept a suggested topic. It does not appear as confirmed before that.
- [ ] Assign a project.
- [ ] Save the same URL again and get a link to the existing item. A different query string stays distinct.
- [ ] An X link stays in the library and asks for pasted text. No summary is invented.
- [ ] Ask a question that the save can answer and open the citation.
- [ ] Ask something you have not saved and get an insufficient-evidence answer.
- [ ] Generate a digest for a range with saves, and another for an empty range.
- [ ] Refresh a project brief, change or delete a cited save, and see the brief marked stale or redacted.
- [ ] Delete the save and confirm the chat answer and digest no longer show its text.
- [ ] Export JSON and confirm it has notes, topics, and projects, and not the API key.
- [ ] Settings do not show secret values.
- [ ] With `AI_PROVIDER=openai` and no key, the app refuses instead of answering with the demo preview.
